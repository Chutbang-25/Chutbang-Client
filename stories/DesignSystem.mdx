# 디자인 시스템

이 디자인 시스템은 일관된 사용자 경험을 제공하기 위한 컴포넌트, 스타일, 가이드라인 모음입니다.

## 색상

디자인 시스템은 세 가지 주요 색상 팔레트를 제공합니다:

- **Primary**: 주요 브랜드 색상 (파란색/보라색 계열)
- **Secondary**: 보조 브랜드 색상 (초록색 계열)
- **Grey**: 중립 색상 (회색 계열)

각 색상은 50부터 900까지 9단계의 명도를 제공하며, WCAG 접근성 가이드라인을 준수합니다.

## 타이포그래피

프로젝트는 **Pretendard** 폰트를 사용합니다. 다양한 폰트 크기와 굵기를 지원합니다.

## 컴포넌트

다음과 같은 기본 컴포넌트를 제공합니다:

- **Button**: 다양한 variant와 size를 지원하는 버튼
- **Input**: 라벨, 에러, 도움말을 지원하는 입력 필드
- **Card**: 콘텐츠를 그룹화하는 카드 컴포넌트

## 사용 방법

각 컴포넌트는 Storybook에서 확인하고 테스트할 수 있습니다. 좌측 네비게이션에서 원하는 컴포넌트를 선택하세요.
